### Задача 10. Угадайка

**Текст задачи.**  
Дана сигнатура метода: `public void guessGame();`  
Метод генерирует случайное число 0–9, считывает ввод, повторяет до угадывания. Выводит количество попыток.

**Алгоритм решения:**

1. Генерируем случайное число `num` от 0 до 9.

   - сравниваем с `num`;
   - если угадал — выходим.
